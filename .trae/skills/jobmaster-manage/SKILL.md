# 投递记录查询与管理

## 流程

1. 读 `data/jobmaster_data.csv`（UTF-8 带 BOM，解析时先去掉 BOM；列定义见 `.trae/rules/project_rules.md`）
2. 按用户意图执行：
   - **查询**：按企业 / 岗位 / 部门 / 行业 / 状态 / 地点 / 时间筛选，输出 Markdown 表格
   - **修改**：用户指令明确（如"把腾讯改成专业面"）则直接执行——更新对应行 `status` 等字段，`notes` 追加 `MM-DD 变更说明`，`updatedAt` 更新为当前时间；同企业多行时先列出候选让用户选
   - **删除**：必须先向用户复述将删除的行，确认后执行
   - **统计**：总数、各状态分布（含待投递）、近 7 天新增、Offer 数、行业分布（`location` 为多值 `;` 分隔，统计地点时需拆分计数）
3. 修改 / 删除后：全量写回 CSV（保留 BOM、CRLF、转义，表头不变）
4. 回复执行结果；行数多时输出汇总表

## 约束

- 删除属于破坏性操作，一律先确认
- `notes` 含换行时注意标准 CSV 转义（引号包裹 + 内部引号双写）
- 完成修改后提醒用户：浏览器打开 index.html 会自动看到变更
