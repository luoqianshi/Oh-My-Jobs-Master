# 新增投递记录

## 输入识别

- **截图**：用 Read 工具读取图片，识别企业名 / 部门 / 岗位 / 招聘页链接
- **链接**：用 WebFetch 抓取页面，从职位页提取企业 / 部门 / 岗位信息
- **文字**：直接解析描述中的企业 / 岗位信息

## 流程

1. 提取字段：
   - `type`：互联网 / 央国企——知名互联网与科技私企 → 互联网；国企央企/银行/运营商/烟草/电网/中储粮等 → 央国企；**无法判断必须询问用户，不要默认**
   - `company`、`department`、`position`、`link`
2. 查重：读 `data/jobmaster_data.csv`，若同企业同岗位存在未终止（status≠已挂）的记录 → 向用户确认是否仍要新增
3. 生成新行（完整列定义见 `.trae/rules/project_rules.md`）：
   - `id`：`jm_` + 13 位毫秒时间戳 + `_` + 4 位 hex
   - `appliedAt`：默认今天（用户提供则以用户提供为准）
   - `status`：简历筛（用户说明已进入某阶段则按用户说法）
   - `source`：截图识别（截图）/ 邮箱提取（邮件）/ 手动创建（纯文字描述）
   - `createdAt` / `updatedAt`：当前时间 `YYYY-MM-DD HH:mm`
4. 全量写回 CSV（保留 UTF-8 BOM、CRLF、标准转义，表头不变）
5. 回复新增行摘要（企业 / 部门 / 岗位 / 类型 / 时间），提醒浏览器打开 index.html 即可看到

## 约束

- 识别不到的字段留空，不要编造
- `type` 无法判断时必须询问用户
- 截图中如有投递时间、进度等信息一并提取，但不确定的宁可不填
