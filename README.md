# Job-Master · 个人秋招工作台

一个**零依赖、单文件**的秋招投递管理应用。浏览器直接打开 `index.html` 即可使用；数据以浏览器本地缓存为准，并自动同步到项目 `data/` 目录，与 Trae AI Agent 共享同一份数据、双向协同。

> 设计语言参考 Cursor CN：暖纸灰浅色主题、墨黑胶囊按钮、衬线标题、等宽眉标、翡翠绿强调色。

---

## ⚡ 快速开始（两种使用模式）

Job-Master 提供两种使用模式——同一份界面、同一份数据模型，按需选择：

### 模式一 · 普通模式（打开即用，全手动管理）

👉 **在线使用**：<https://luoqianshi.github.io/Oh-My-Jobs-Master/>

1. 点击上方链接直接打开（或下载仓库中的 `index.html` 双击打开）；
2. 在「投递列表」点「＋ 新增投递」录入企业 / 岗位 / 行业 / 地点；在「进度看板」拖拽卡片更新阶段；
3. 所有数据实时保存在**浏览器本地缓存**（localStorage）中，关闭页面不丢失——数据完全留在你自己的设备上，不上传任何服务器；
4. 在「数据管理」页可**一键导出 CSV** 持久化到本地磁盘，之后随时导入恢复或迁移到其他浏览器。

### 模式二 · TRAE 模式（AI Agent 帮你打工，浏览器与 Agent 共管同一份数据）

适合想把「记录与管理」交给 AI 的用户，四步接入：

1. **克隆项目**并用 TraeCode 打开：

   ```bash
   git clone https://github.com/luoqianshi/Oh-My-Jobs-Master.git
   # 用 TraeCode 打开 Oh-My-Jobs-Master 文件夹
   ```

2. **手机远程指挥电脑**：在 TraeCode 中启用「手机控制电脑」功能（TRAE 手机端绑定电脑）并保持项目打开——
   - **碎片时间**：在个人手机的微信群里浏览筛选感兴趣的秋招信息，把推文转发给手机端 TRAE 并说一句「帮我新增为待投递」——电脑上的 Trae Agent 会自动解析推文 / 截图 / 链接（企业、岗位、地点），在 `data/jobmaster_data.csv` 中创建一条「待投递」记录；
   - **专注时间**：打开浏览器进度看板，把「待投递」列的卡片逐一批量投递，拖拽即可更新状态；
3. **配置个人求职邮箱**：参照 `config/secrets.example.json` 创建 `config/secrets.local.json`（在邮箱网页版「设置 → POP3/SMTP/IMAP」开启 IMAP 服务并生成客户端授权码）；
4. **定时同步投递反馈**：每天对 Trae 说一句「同步一下今天的邮件」，Agent 会运行 `scripts/fetch_emails.py` 采集求职邮箱新邮件，自动识别笔试 / 面试 / Offer / 感谢信等通知，更新对应投递的状态、备注与最新日期，并输出变更汇总——进展跟踪从此不用人工翻邮箱。

> **双向同步机制**：浏览器改动每 60 秒 / 切走标签页 / 关页前自动落盘到 `data/`；Agent 或脚本修改 CSV 后，页面获得焦点时按「更新时间较新者胜」自动行级合并——浏览器与 Agent 永远共享同一份真相。

## 一、功能清单

### 核心模块

| 模块 | 功能 |
|---|---|
| 投递列表 | 记录每一条秋招投递（企业名称/部门名称/当前状态/目标岗位/所属行业/工作地点/最新日期/链接/备注）；关键词搜索（企业/岗位/部门/地点）；按行业、状态筛选；表内直接下拉改状态；**拖拽行手柄调整顺序 + 行置顶**（见下） |
| 进度看板 | 预设 8 个阶段（待投递 → 简历筛 → 笔试筛 → 专业面 → 主管面 → HR面 → Offer / 已挂）横向看板，自定义状态自动追加为看板列；拖拽卡片即变更进度并自动追加备注历史 |
| 公司信息 | 校招官网速查画廊（读取 `data/companies.csv`，只读）。顶部搜索框实时匹配公司名 / 行业；下方一行行业筛选 tab（含「全部」，每个 tab 带公司数），点击只展示属于该行业的公司，一家公司可归属多个行业；公司卡片大字展示名称、小字展示招聘链接、左下角彩色标签标注所属第一行业，点击卡片新标签页直达校招官网 |
| 邮箱收件 | 展示 Agent 经 IMAP 脚本采集的邮件池；未读圆点标记待处理邮件；一键「创建投递」自动清洗企业名并预填；可忽略无关邮件 |
| 数据管理 | 投递漏斗统计（累计/近 7 天/各状态/Offer/行业分布，数字滚动动画）；目录同步状态面板；CSV 导入/导出（按更新时间行级合并）；清空本地缓存 |

### 列表排序与置顶（2026-09-17 更新）

投递列表支持两种排序方式，工具栏「排序方式」下拉切换：

- **按最新日期排序（默认）**：非置顶行按 `latestDate` 降序自动排列；
- **手动顺序**：拖拽每行最左侧的 **6 点手柄** 即可上下调整行序，拖动时目标行显示绿色插入指示线；在自动排序下首次拖动会自动切换为手动顺序并固化当前显示顺序。

**行置顶**：点击每行操作列的 **图钉按钮**，该行立即固定到列表最上方（浅绿底色 + 绿色「置顶」标签 + 图钉高亮），再次点击取消置顶。置顶行始终排在最前，与排序方式无关，适合作为「重点关注 / 待跟进」标记。

> 排序与置顶状态存于浏览器本地缓存（`localStorage`），刷新、切换视图后保持；行顺序同时随 CSV 行序落盘（目录授权或支持 PUT 的服务器），只读 HTTP 同步下以本地记忆为准。

### 字段预设与自定义（2026-09-15 更新）

- **当前状态**：预设 `待投递 / 简历筛 / 笔试筛 / 专业面 / 主管面 / HR面 / Offer / 已挂`（「待投递」为投递前状态，看板首列）；表单下拉中选择「＋ 新增状态…」即可自定义，新状态持久保存并自动加入下拉列表、看板列、筛选器与统计（Agent / CSV 导入写入的新状态也会被自动收录）；选择「－ 删除自定义状态…」并按序号或名称确认，即可删除不需要的自定义状态（预设状态不可删除；被投递记录使用中的状态需先修改后再删）
- **所属行业**：预设 `银行 / 制造 / 车企 / 互联网 / 央企 / 证券`；表单下拉中选择「＋ 新增行业…」即可自定义，新行业持久保存并自动加入下拉列表（Agent / CSV 导入写入的新行业也会被自动收录）；选择「－ 删除自定义行业…」并按序号或名称确认，即可删除不需要的自定义行业（预设行业不可删除；使用中的行业需先修改后再删）
- **工作地点**：预设 `杭州 / 上海 / 广州 / 天津 / 合肥 / 北京 / 深圳 / 南京`；表单中复选多选，多选面板中选择「＋ 新增地点…」即可自定义，新地点持久保存并自动勾选（Agent / CSV 导入写入的新地点也会被自动收录）；自定义地点在面板中带「×」删除按钮，点击即可删除（预设地点不可删除；使用中的地点需先修改后再删）；表格内渲染为彩色地点标签，数据以 `;` 分隔存储（如 `上海;北京`）
- **最新日期**：与该投递最新进展相关的日期，可为未来日期（如笔试/面试安排）

### 数据与同步架构（2026-09 最新更新）

**本地缓存优先，三层持久化：**

1. **浏览器本地缓存（第一优先）**：所有变更实时写入 `localStorage`，即使同步未启用数据也绝不丢失；
2. **定时自动保存到本地目录**：每 **60 秒**、切换标签页、关闭/刷新页面前，自动把缓存中的变更冲刷写入数据目录（目录授权模式写 CSV 文件；HTTP 模式 PUT 到 `./data/`）；
3. **外部变更自动合并**：页面获得焦点 / 每 60 秒自动检测 `data/` 目录中 Agent 或脚本的外部修改，按「更新时间较新者胜」做行级合并。

**两种目录同步通道（自动选择，目录授权优先）：**

| 通道 | 触发条件 | 读 | 写 |
|---|---|---|---|
| HTTP 同步（默认） | 页面经本地/预览服务器访问 | 自动 GET `./data/`，零配置 | PUT 写回；服务器不支持时自动降级为**只读同步**并在指示器提示 |
| 目录授权同步 | 用户在「数据管理」中授权 `data/` 目录（File System Access API） | 自动 | 完整读写，刷新后仍保持授权 |

### 其他能力

- 侧边栏可折叠/拖拽调宽；**收起后隐藏箭头，点击品牌 Logo 即可复原**
- 表格状态列渲染为彩色状态胶囊（预设 8 种状态 8 色）；行业与工作地点渲染为彩色标签 pill，自定义行业 / 状态 / 地点自动从调色板取色
- CSV 导出带 BOM，可直接用 Excel 打开；导入自动按更新时间合并去重，旧版表头（type/appliedAt）自动迁移为 industry/latestDate
- 全部操作有 Toast 反馈（成功 ✔ / 失败 ⚠）

## 三、技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 载体 | 单文件 `index.html` | 零外部依赖、零构建，双击即用 |
| UI | 原生 HTML/CSS/JS | CSS 变量主题系统；事件代理；模板字符串渲染 |
| 持久化 L1 | `localStorage` | 投递数据 + UI 偏好（折叠/宽度/当前视图/排序方式/置顶行/手动顺序）+ 自定义行业 / 状态 / 工作地点 |
| 持久化 L2 | File System Access API | 目录授权模式；句柄存于 IndexedDB，跨会话恢复 |
| 持久化 L2' | fetch GET/PUT | HTTP 模式对接 `./data/`；Last-Modified 变更检测 |
| 定时器 | setInterval / setTimeout 防抖 | 60s 定时落盘；输入防抖 500ms 写回；焦点回归 800ms 合并 |
| 数据格式 | CSV（UTF-8 BOM + CRLF） | 标准转义；全量读取 → 内存修改 → 覆盖写回 |
| 采集脚本 | Python 3.8+ 标准库 | `scripts/fetch_emails.py` IMAP 拉信，零第三方依赖 |

**数据文件：**

- `data/jobmaster_data.csv` — 投递主数据（唯一真相）。列：`id,company,department,status,position,industry,location,latestDate,link,source,notes,createdAt,updatedAt`；id 规则 `jm_时间戳_4位hex`；`industry` 预设 银行/制造/车企/互联网/央企/证券（支持自定义），`location` 多值以 `;` 分隔（预设 杭州/上海/广州/天津/合肥/北京/深圳/南京，支持自定义），`status` 预设含「待投递」共 8 个枚举（支持自定义；自定义状态 / 地点存于浏览器 localStorage，无需改动 CSV 结构）
- `data/emails.json` — 邮件池。每封含 `processed / matchedEntryId / matchedAction` 处理状态回写
- `data/companies.csv` — 公司校招官网信息（「公司信息」板块只读数据源）。列：`序号,公司名称,招聘链接,所属类型,数据来源`；同名公司自动聚合为一张卡片、所属类型合并为多个行业；行业标签颜色复用全局调色板，新行业无需改代码

## 四、使用方式

1. **打开应用**：双击 `index.html`（Chrome/Edge），或经本地服务器访问（如 `python -m http.server 8765`）——后者自动启用 `./data` HTTP 同步；
2. **记录投递**：点「新增投递」手动录入，或在 Trae 中对 AI 说「帮我同步今天的秋招邮件」「我投了 XX 帮我记录一下」由 Agent 代写；
3. **协同工作流**：浏览器改动 → 定时自动写回 `data/`；Agent 修改 CSV → 页面获得焦点时自动合并，双方始终共享同一份数据。
